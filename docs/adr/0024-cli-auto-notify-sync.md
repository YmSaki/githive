# ADR-0024: CLI の自動通知を元の書き込みと同期する

- 状態：採用
- 日付：2026-11-11

## 文脈

Issue の担当変更、Task の再割当、Chat のメンションで通知を生成しても、元の ref しか同期しないため相手には通知が届かなかった（#144）。通常の CLI 書き込み完了後に手動同期が必要なことは、既定の自動同期と整合しない。

## 決定

CLI の自動同期は対象 ref に加えて notify/stream も同期する。既存の全名前空間 fetch と一括 push を使い、ストリームが存在しなければ push 対象は増えない。notify 自身の操作では重複して指定しない。`--no-sync` ではどちらも送信せず、失敗時のローカル変更と警告の扱いは維持する。

ADR-0011 の CLI 自動通知が次の明示 sync までローカルに留まるという記述を置き換える。MCP の書き込みが自動同期しない決定は変更しない。イベント形式・fold 意味論は変更しない。
